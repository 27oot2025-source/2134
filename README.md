# СССР://2077 — Государственный Терминал Союза

Сайт в стиле **советского киберпанка**: альтернативная вселенная, где СССР не распался.

## Состав

| Раздел | Содержание |
|--------|------------|
| **22 вкладки** | Главная, Лор, Карта, Персонажи, Магазин, Кибертехника, Транспорт, Правда-2077, Радио, Кино, Библиотека, Архив КГБ, Космос, Наука, Кухня, Игротерминал, Терминал, Удостоверение, Погода, Курсы, Доска почёта, Связь |
| **Магазин «ГОСТ»** | 20 товаров, у каждого — уникальное фото, подробное описание и характеристики; корзина и оформление заказа |
| **Лор** | Хроника с 1917 по 2077, 6 фракций, глубокая альтернативная история |
| **Карта мира** | 18 держав, свои флаги (скачаны), идеологии, досье, фильтры по блокам |
| **Персонажи** | 6 героев, у каждого уникальное фото и полное досье с цитатой и характеристиками |

## Технологии

- Чистый HTML + CSS + JavaScript (без сборки и зависимостей)
- `js/data.js` — база данных вселенной
- `js/app.js` — навигация, рендер, корзина, игра «Гадюка-8», терминал
- Интерфейс полностью на русском языке

## Запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Структура

```
index.html      — разметка всех 22 вкладок
css/style.css   — стили (неон, CRT, советская типографика)
js/data.js      — контент: лор, товары, страны, персонажи…
js/app.js       — логика терминала
assets/flags/   — флаги держав
assets/chars/   — фото персонажей
assets/products/— фото товаров
assets/img/     — hero, космос, лаборатория, постеры
```
